# volley-reel

DataVolley のスカウトファイル（.dvw）と試合動画を同期させ、
選手に見せるハイライト動画（MP4）を作るローカルアプリ（Windows / オフライン / Electron）。

- 設計図: [docs/design.md](docs/design.md)
- 状況: M0（書き出し検証）完了、M1（取り込み・DVW パース・再生）、M2（検索・絞り込み・自チーム設定・名寄せ）、M3（リール・マーカー・並べ替え・通し再生）、M4（クリップごとの IN/OUT）、M5（注釈）、M6（スコアボード・選手テロップ・タイトルカード）、M7（MP4 書き出し）、M8（元に戻す・保存の堅牢化・再リンク・ショートカット一覧）実装済み

## 準備

1. `vendor/ffmpeg/bin/` に ffmpeg.exe / ffprobe.exe を置く（gyan.dev の essentials ビルド。git 管理外）
2. （同梱するときだけ）`vendor/packs/<id>/` に選手写真パック（`manifest.json` と `photos/`。倉庫の `addons/<id>/` と同じ形。git 管理外）を置く。インストーラーに入り、開発版でも読まれる。リリース先は公開リポジトリなので、`npm run release` は `vendor/packs` にパックがあると止まる（入れて公開するときだけ `VR_RELEASE_WITH_PACKS=1`）。ふだんはパックを `.vrpack` でモニターに渡す
3. `npm install`

## 使い方

```bash
npm run dev        # 開発モードで起動
npm run build      # out/ にビルド
npm start          # ビルド結果を起動
npm test           # DVW パーサーのテスト
npm run typecheck
```

1. 起動すると**倉庫**と**プロジェクト**の一覧が出る。最初に倉庫のフォルダを選ぶ（`library.json`、`matches/*.json`、`cache/` ができる）
2. 倉庫に試合を入れる
   - 「フォルダから一括取り込み」: 動画と DVW のあるフォルダ（複数可）を選ぶと、日付とチームコードで組にして一覧にする。確認して取り込む
   - 「1試合を取り込む」: 動画と .dvw を1つずつ選ぶ
   - 再生できる形式（H.264 4:2:0、音声 AAC など）は**元の動画をそのまま参照**する。リニアPCM 音声（XAVC S）は音声だけ外したコピーを、4:2:2 / 10bit などは変換したものを倉庫の `cache/` に作る
   - 動画や DVW を移動・改名すると、倉庫の行とプロジェクト画面の上に「動画が見つかりません」と出る。「場所を指定…」で今の場所のファイルを選ぶと指し直す（動画は長さ、DVW はチームが元と違えば知らせる）
3. 「新しいプロジェクト」: 対象チームを倉庫にあるチームの一覧から 1 つ選び（倉庫に `HTH` があれば最初から入る）、そのチームの試合を抽出し、使う試合を選んで「作成」。プロジェクトは倉庫の `projects/<プロジェクト名>/` に自動で作る（同じ名前があれば「(2)」を付ける。名前が空なら「<チーム> プロジェクト」）。ほかの場所に置きたいときは「場所を選んで作成…」。上部の「試合」ボタンであとから足す・外す。「ホーム」で一覧に戻る
   - 以前の形式のプロジェクトを開くと、中の試合が倉庫に移る（古い `matches/` は名前を変えて残す）
4. 左のプレー一覧をクリック（または ↑ ↓ キー。↑ ↓ は最後にクリックした側の一覧を動く: 右のシーン欄をクリックしたあとはシーンのクリップを上下）すると、そのプレーから再生する（別の試合のプレーなら動画も切り替わる）。「切り出し」が「プレー前後」のときはキープレーの前後だけを再生し、終わると一覧の次のプレーへ自動で進む（クリップを選ぶか通し再生で止まる）
5. 絞り込み: 左上で「すべての試合」か1試合を選ぶ（既定はすべての試合。試合ごとに見出し行が入り、各試合の中は時系列。試合の並びは「古い試合から / 新しい試合から」で選ぶ）。「切り出し」でシーンに入れるときの長さを選ぶ: 「プレー前後」（キープレーの前後）か「ラリー終わりまで」（キープレーの少し前からラリーの最後まで。秒数はシーンの欄で設定）。チーム（すべて / 対象チーム / 相手。対象チームはホームでもアウェイでも自チーム）、選手、スキル、評価、セット、ローテ、開始・終了ゾーン
   - 選手は DataVolley の選手IDで、試合をまたいで同じ人として扱う（ホーム/アウェイ、紅白戦の `-a` も統合）
   - 「ローテ」は対象チームのローテ、「相手ローテ」は相手チームのローテ（どちらのチームのプレーでも、そのときのローテで絞り込む。対象チームが分からない試合はホームを対象チームとみなす）
   - 「向き」: ボールが画面の下から上へ（↑）か、上から下へ（↓）向かうプレーに絞る。サーブ・アタックは打ったチームのコートから、レセプション・ディグ・ブロックは相手のコートから来る向き。セットには向きがない（向きで絞ると出ない）。コートのグリッドを合わせた試合だけ分かる（合わせていない試合のプレーは除く）。一覧の行にも ↑ ↓ が出る
   - 全部ホーム入力の試合はチームを区別できないので、チームで絞っても全プレーを含める
   - 「試合の状況」: セット・ローテ・相手ローテ・局面・直前・直後は、たたんだ欄にまとめてある（見出しに使っている条件の数が出て、条件が入っていると開く）
   - 「詳細」: テンポ（H High・M Half・Q Quick など）、アタックの打ち方（Hard・Soft・Tip）、コンビ（アタックのコンビネーションとセッターコール。DVW の表の名前つき）で絞る。スキルを選ぶと、そのスキルにあるものだけが出る
   - **保存条件**: 条件を選んだら一番上の「＋ 今の条件を保存」で名前を付けて保存する（Enter で確定、Esc でやめる）。保存した条件はチップになり、クリックでその条件に戻る（今の条件と同じならチップが光る）。同じ名前で保存すると中身を置き換え、右クリックで外す（Ctrl+Z で戻せる）。保存先はプロジェクトの `project.json`。試合の選択（すべての試合 / 1試合）と「切り出し」は含めない
   - **コートのグリッド**（CourtEnd Vision から）: 動画の下の「コート」→「グリッドを合わせる」で、四隅の丸をコートの角（エンドラインとサイドラインの交点）にドラッグし「完了」。四隅は試合ごとに倉庫の `matches/<id>.json` に保存される。グリッドはコートを 3 列 × 6 行（DVW のゾーン）に分ける。「プレーのゾーン」は選んだプレーの開始ゾーンを緑、終了ゾーンを赤で塗り、開始から終了へ矢印を引く。隣の選択で「サブゾーン」にすると、ゾーンを4分割した A〜D で塗り、矢印もその中心から中心へ引く（終了のサブゾーンは DVW のコード、開始のサブゾーンはサーブ・トス・アタックのクリック位置から。分からないところはゾーン全体）。トスは上げた位置（DVW のトスのゾーン）から、続く同じチームのアタックの開始位置へ。「手前（第1セット）」は第1セットでカメラ側にいるチーム（セットごとに入れ替わり、第5セットは8点で入れ替わる）。色・濃さ・線の太さは ⚙ で選ぶ（このパソコンの設定）。書き出しに入れるときは、クリップの下の「自動表示」の「コート（書き出し）」にチェック（その動画のすべてのクリップ。見た目はプレーヤーと同じ。コートを合わせた試合だけ）
     - どちらのチームが手前かは、合わせるときに選ぶ「手前（第1セット）」から決める。セットごとに入れ替わり、5 セット目は 4 セット目と同じ側で始めて、どちらかが 8 点になったら入れ替える
     - サーブの開始ゾーンはエンドラインの後ろ（奥行きはゾーン 1 列分）を 5 つに分け、ゾーン 1 側から 1-9-6-7-5 で塗る。レセプションの開始（サーブを打った場所）も同じ。1・9・6・7・5 以外が入っているときはコートの中のゾーンを塗る
     - 「コート」タブの選択を「座標（点）」にすると、スカウトがクリックした位置を開始は緑、終わりは赤の点で出し、矢印で結ぶ（書き出しも同じ）。レセプション・ディグは、答えた相手のサーブ／アタックの座標（ボールが来た位置）を使う。ブロックなど座標がないプレーや、座標のない DVW はゾーンを塗る
6. 右上の**動画**: シーンを並べたもの。新しい動画は空で始まる（シーンは「シーンを追加」「新しいシーン」で入れる）。シーンの選択欄は「この動画のシーン」と「ほかのシーン」に分かれる。シーン・動画名の横（とマーカー）の「カード」をクリックしてタイトルカードの表示を切り替える（出すときは色付きの太字を角の丸い枠で囲む、出さないときは灰色の文字だけ。動画の設定どおりのときはボタンの説明にそう出る）。「シーンを追加」「新しいシーン」で組み、↑↓かドラッグで並べ替える。同じシーンを複数の動画で共有でき（「共有 n」と表示）、シーンを直すとすべての動画に反映される。「⚙ 設定」（動画の設定）（配色・スコアボード・テロップ・タイトルカード）は動画ごとの設定。「▶ 動画を再生」も動画単位（書き出しは右下の「書き出し」）
7. 右下の**シーン**: プレー一覧の行の **1〜5** ボタンでそのマーカー付きでクリップを入れる（同じ番号をもう一度押すとマーカーを外す）。まとめて入れるときは「結果をシーンに追加」。シーンは `reels/<id>.json`、動画は `videos/<id>.json` に自動保存（削除すると `deleted/` に移動）
   - **書き出し（と再生）に使われないクリップ**: 「再生・書き出し」が「マーカー付きだけ」のときのマーカーなしのクリップ、番号をクリックしてオフ（灰色）にしたマーカーのグループ、「プレーが見つかりません」のクリップ、今の動画に入っていないシーン。それぞれ欄に「使わない」「オフ」などと出る
   - マーカーを付けると、そのグループの中では時系列の位置に入る（並べ替えはドラッグで）
   - マーカー 1〜5 でグループ分けし、グループに名前を付けられる。マーカーごとの「カード」でその前にタイトルカードを出すか決める（既定は動画のオーバーレイ設定）。マーカーの番号をクリックするとオフ（灰色）になり、そのグループを再生・書き出しに使わない（クリップは残る。もう一度クリックで戻る）。
   - シーンの名前・マーカーの名前（タイトルカードに出る）は、名前をクリックしてその場で編集する
   - ⚙（動画名の横・シーン・マーカー）: そのタイトルカードを動画の画面で編集する。「図形・文字」でそのカードに文字・画像・図形を置き、「タイトルの位置」でタイトルをドラッグで移動・右下の角か「大きさ」で拡大縮小（位置と大きさはその動画の同じ種類のカードすべてに使う）。「このカードを出す」で表示を切り替える。「文字」でカードに出す文字を名前と別に決められる（改行で 2 段。空なら名前）。「背景」でカードの背景色（この動画のすべてのカードと無地のスライド。「配色に戻す」で元の色）。背景色は「⚙ 設定」（動画の設定）でも変えられる。動画名のカード（動画の頭）は「⚙ 設定」（動画の設定）でも出せる
   - マーカーは 1 つのクリップに複数付けられる（例: 1 と 3）。そのクリップは両方のグループに入り、それぞれの場所で再生・書き出しされる。ドラッグで別のグループへ動かすと、そのグループの分だけが移る
   - 動画のシーン一覧・シーンのマーカーのグループとクリップは、左の ⠿ をドラッグして並べ替える。落とす場所に線が出る（× で外す）。アタックのクリップにはコンビのコードが出るグループ同士・グループ内の順序は ↑↓ かドラッグで並べ替え
   - 書き出し範囲: 「マーカー付き」はマーカーのグループ順、「全部」はその後にマーカーなしを時系列で
   - 「▶ シーンを再生」でそのシーンだけを順に再生（試合をまたぐと動画が切り替わる）
   - **動画の下の欄**: 再生バーの下のタブ「トリム」（見出し・IN / OUT・スロー・停止。編集のふだんの画面）「図形」「表示」（自動表示）「コート」で、1 つずつ開く。開いているタブをもう一度押すと閉じて、動画がいちばん大きくなる（どのタブを開いていたかはこのパソコンで覚える）。動画の上で図形を選ぶか見出しの「書式」を押すと「図形」が開く（「トリム」を開いているときはそのまま）。トリム・図形・表示はクリップを選ぶと使える
   - **最大化**: 再生バー右端の ⛶ か `M` で、動画だけを画面いっぱいに出す（スコアボード・テロップ・図形も一緒に大きくなる。試合をまたぐ通し再生でもそのまま）。`Esc` か 🗗 で戻る（`Esc` は再生を止めない）。「▶ 動画を再生」「▶ シーンを再生」の横の ⛶ は最大化して再生し、終わると（■ で止めても）元に戻る
   - 長さの初期値はリールごとに「ラリー全体」（サーブ −1.5 秒〜最後のプレー +2.5 秒）か「キープレー中心」（−3〜+4 秒）。秒数も変えられる
   - リールのクリップをクリックすると、その範囲をループ再生しながら動画の下のトリムバーで IN/OUT を詰められる
     （つまみをドラッグ、`[` `]` キー、またはキープレーからの秒数を入力。「既定に戻す」で初期値に戻る）。「ループ再生」のチェックを外すと OUT を過ぎても再生を続ける
     - **スロー・停止**: トリムバーの下の「＋ スロー」で再生位置から 1 秒を 0.5 倍に、「＋ 停止」で再生位置のコマを 2 秒止める。範囲（キープレーからの秒。◎ で再生位置）・速さ（×0.75 / ×0.5 / ×0.25）・止める秒数は横の欄で変え、× で外す。1 つのクリップにいくつでも置ける。ループ再生・通し再生・書き出しのどれでも同じように効き、クリップの長さ（「再生 ○ 秒」）とシーン・動画・書き出しの長さにも入る。止めている間は、その時刻に出ている図形が出たまま（書き出しも同じ）
     - 図形を選ぶと、トリムバーにその表示区間が橙の線で出る。線の両端をドラッグして出る時刻・消える時刻を決める（ほかの図形の出る・消える時刻、IN・OUT、キープレーの近くでは吸着し、青い点線が出る。Alt を押すと吸着しない）。「▸ 図形の表示時間」でクリップの図形すべての表示区間を一覧し、そこでもドラッグできる
   - 同じ試合で範囲が重なるクリップ（同じラリーの2プレーなど）には ⚠ が付く。警告だけで、両方残る
   - 注釈: 選択中のクリップの動画の上に、テキスト・矢印・円・四角・三角形・折れ線・多角形・フリーハンドを描ける。「画像・PDF…」で画像ファイルか PDF（1ページ目）を置ける（プロジェクトの `assets/` にコピーする）。スクリーンショットやほかのアプリでコピーした画像は `Ctrl` + `V` で中央に貼り付けられる（PNG で `assets/` に保存）
     - 選択ツールでクリックして選び、ドラッグで移動、ダブルクリックでテキストを編集、`Delete` で削除
     - 選んだ図形のつまみで大きさを変える（Shift で縦横比を保つ。画像は縦横比を保ち、Shift で外す）。矢印は両端
     - 「頂点の編集」で頂点のつまみになる: 頂点を動かす、辺の中点を引くと追加、頂点をダブルクリックで削除。四角・円は多角形になる
     - 書式の欄（Office 風）: 線の色・太さ・種類、塗りと透明度、矢印の先、テキストのサイズ・太字・縁取り・枠付き（枠の塗り・透明度・枠線・余白）、全体の透明度
     - 「ここから表示」「ここで消す」で出し入れの時刻を決める（既定はクリップ全体）。時刻は動画上の絶対時刻で保存するので、IN を詰めてもずれない
     - 画像は「トリミング」で切り取る: 枠のつまみで範囲、画像のドラッグで位置、ホイールか ＋／− で拡大・縮小（枠はそのまま）。「元の画像に戻す」で全体に
     - 画像に遠近をつける（データ分析ソフトのヒートマップなどをコートに重ねる）: 画像を選び「遠近」で「遠近をつける（この位置で）」か、コートのグリッドを合わせてあれば「コート全体／手前のコート／奥のコートに合わせる」。四隅のつまみを1つずつドラッグして合わせる。手前のコートはネットが画像の上、奥のコートはネットが画像の下。反対側から見た図なら「180°回転」。先に「トリミング」で画像をコートの線までにしておくとぴったり合う（遠近をつけた画像はトリミングできない。「遠近なし」で戻る）。「透明度」で下の映像を透かす。書き出しにも入る
     - テキストは Alt+Enter（または Shift+Enter）で改行できる。Enter で確定
     - 頂点の編集中・矢印の端は、Shift を押しながらドラッグすると隣の頂点（矢印はもう一方の端）と縦か横がそろう位置に吸着する（辺が垂直・水平になる）
     - Shift+クリックで図形を選び足し、「グループ化」でまとめると一緒に選択・移動・削除できる（「グループ解除」で戻す）
     - 自由に選んだ色は「マイカラー」として色の見本に残る（右クリックで外す）。倉庫に保存し、すべてのプロジェクトで使える
     - **パレット**（右下、シーン欄の下の「▶ パレット」で開閉）: 選んだ図形（グループごと）を名前を付けて保存し、ほかのクリップ・カード・プロジェクトで「入れる」。出る・消える時刻もクリップの IN からの秒で保存し、入れたクリップで同じタイミングになる（タイトルカードでは常に表示）。倉庫に保存（画像も倉庫にコピーし、使うときにプロジェクトへコピー）。同じ倉庫を使うすべてのプロジェクトで共通。ドラッグで並べ替え、🔒 で保護（保護中は × が出ず外せない）
       - タブでカテゴリ分け: 「＋」でタブを足し、ダブルクリックで名前を変える（空のタブは × で削除）。開いているタブに「選択を保存」が入り、アイテムをタブに落とすとそのカテゴリへ移る（「すべて」に落とすとカテゴリから外す）
       - 「⧉ 浮かせる」でパレットを画面の上に浮かせて広く使える（見出しのドラッグで移動、右下の角で大きさを変える。位置と大きさは覚えておく）。「⧉ 戻す」で右の列に戻る
   - **スライド**: シーン欄の行を右クリックするとその下に、グループの見出しを右クリックするとグループの先頭にスライドを入れる。スライドは止まった 1 枚の画面で、クリップと同じように再生・書き出しされる
     - 「無地のスライド」: タイトルカードと同じ色の無地。「PDF・画像を読み込む…」: PDF は全ページが 1 枚ずつ、画像は複数選べて名前順（`スライド2` → `スライド10`）。PowerPoint は「エクスポート → PDF」で書き出したものを読み込むのがおすすめ（4:3 のページは左右に黒い帯）。「今の画面を静止画に」: 動画の今のコマを背景にする
     - スライドの行をクリックすると動画の画面に出て、タイトルカードと同じ道具で文字・図形・画像を置ける。表示の秒数（既定 3 秒）は下の欄で変える。「完了」かクリップのクリックで戻る
     - スライドは直前のクリップに付いていく（クリップを並べ替えると一緒に動く。クリップを外すと、その前のクリップの後ろに残る）。⠿ のドラッグで別の位置・別のグループへ。× で外す
     - マーカーのグループがスライドだけでも再生・書き出しされる（スライドだけのシーンも作れる）。マーカーなしの欄のスライドは「全部」のときだけ使う
     - PDF・画像から入れたスライドは元のファイルの場所を覚えている。元のファイルが新しくなると（PowerPoint で直して同じ名前で書き出し直すなど）、アプリに戻ったときに「スライドの元のファイルが更新されています」と出る。「読み直す」で同じページの画像に入れ替わる（置いた図形はそのまま）。ページが減った・増えたときは知らせる。スライドの編集欄の「元のファイルを読み直す」でもできる
   - **書き出し**（右下の「▶ 書き出し」）: 書き出す範囲（すべて書き出し／シーンごとに書き出し／開いているシーンだけ／マーカーのグループだけ）を選び、「MP4 に書き出す」。長さと出力（720p・フェード・タイトルカード）を確認でき、進み具合とキャンセルもここ
     - 「すべて書き出し」は YouTube のチャプター（`<動画名> チャプター.txt`）も MP4 の隣に書き出す。`0:00 シーン名` の形で 1 行ずつ。マーカーのグループが 2 つ以上あるシーンは `シーン名 - マーカー名` でグループごと。時刻は書き出した動画の実際の長さから計算し、最初は必ず 0:00（動画のカードを含む）。YouTube は 10 秒未満のチャプターや 3 つ未満だと使わないので、そのときは書き出しの結果に出す。説明欄に貼り付けて使う。そのあとに 1 行空けて、チャプターごとに名前とリンク（`https://youtu.be/〇〇〇〇〇〇〇〇〇〇〇?t=秒`）も書く。動画を上げたら「〇」11 文字を動画の ID に置き換えると、各チャプターに飛ぶリンクになる
     - 「シーンごとに書き出し」: 動画のシーンを、動画の中と同じ形（シーンのカード → クリップ）で 1 本ずつ書き出す。フォルダを 1 回選ぶと、シーンの名前のファイル（`サーブ.mp4` など。同じ名前は `(2)` を付ける）を順に書き出す。同じ名前のファイルがあれば上書きしてよいか聞く。途中でキャンセル・失敗すると残りは書き出さない
     - 図形ごとのフェード: 「全体」欄の「フェードイン / アウト」（秒）。出るとき透明から、消えるとき透明へ（書き出しも同じ）
     - **表示範囲**: 選んだ図形の「全体」の欄で「このクリップ / マーカー全体 / シーン全体 / 動画全体」を選ぶ。マーカー全体はそのマーカーのグループのすべてのクリップ（紫の枠）、シーン全体はそのシーンのすべてのクリップ、動画全体はその動画のすべてのクリップに出る（タイトルカードには出ない）。どのクリップからでも直せて、すべてに反映される。選択枠の色とタグ（シーン全体＝橙、動画全体＝緑）で見分ける。「ここから表示 / ここで消す」はこのクリップの図形だけ
     - 動画の下の「見出し」の欄（図形の欄とは別）に入力すると、そのクリップの動画の中央上部にテキスト（白・黒縁・サイズ 48）が出る。消すと見出しも消える。「書式」で色・サイズ・枠・表示範囲を変えられる。テキストは図形の T でも置ける（既定は白文字・黒縁）
     - 新しい図形の色は赤が既定
     - 四角・円・多角形は「線なし」で塗りだけにできる
     - 動画の下の「自動表示」の行で、スコアボードの位置（左上・中央上・右上、動画全体）を選べる。右端の ⚙ でタイトルカードの秒数（シーン・マーカー共通）
     - オーバーレイの配色（スコアボード・テロップ・タイトルカード）は「設定」でプロジェクト全体に決める
     - クリップとカードの切り替えのフェード（イン・アウト）は動画ごとの設定（「⚙ 設定」（動画の設定）か「自動表示」の ⚙）。書き出しは各クリップ・カードの頭と終わりを黒からフェード、プレビューの通し再生でもクリップに近い見た目で確かめられる
     - 「設定」の「チームのロゴ」でチームコードごとにロゴ画像を選ぶと、1 試合のクリップだけのタイトルカードに相手のロゴが出る（倉庫の `logos/` に保存し、全プロジェクト共通）
     - 座標は動画に対する 0〜1 で保存。編集中は、今の時刻では表示されない注釈も薄く表示する
   - 自動オーバーレイ: スコアボード（ラリー開始前の点数、自チームが左）と選手テロップ（背番号・名前・スキル・評価）を
     DVW から自動で表示（スコアボードは既定で左上。動画の下の「自動表示」のチェックで、動画全体でオフになっていても表示に戻せる）。動画の「⚙ 設定」（動画の設定）で、要素ごとに表示・位置・サイズ・項目を設定
     - タイトルカード（マーカーグループの頭、マーカー番号・マーカー名・試合名）も選べる。番号は「マーカー番号」を外すと出さない（その場所は細いアクセントの帯になる）。通し再生ではグループの前に設定秒数だけ出る
     - クリップごとに、動画の下の「自動表示」でスコアボード／テロップを隠したり、テロップの名前・2行目を書き換えたりできる
       - テロップの名前は、横の選択が「動画全体（この選手）」（既定）なら、この動画の同じ選手のすべてのクリップに使う（選手 ID で見るので試合をまたいでも同じ。外国人選手の姓名の順を直すときなど）。「このクリップだけ」にすると、そのクリップだけ別の名前になる。空欄に戻すと DVW の名前
     - 「写真」をオンにすると（既定はオフ）、選手写真パックにそのプレーの選手の写真があれば、テロップの上（テロップが下のとき）か下（テロップが上のとき）に出す（背景は透過のまま、テロップ側にアクセント色の線）。テロップの左・中央・右に合わせる。書き出しにも入る。写真がない選手はテロップだけ
   - 「MP4 に書き出す」（右下の「書き出し」）: 動画のシーンを順に、各シーンの書き出し範囲のクリップを、通し再生と同じ順（タイトルカード込み）で MP4（H.264、音声なし）にする
     - 出力は 720p・素材のフレームレート。既定の保存先はプロジェクトの `exports/`
     - 注釈・スコアボード・テロップ・タイトルカードは、プレビューと同じ描画で PNG にして焼き込む。表示時刻のある注釈は `enable` で出し入れ
     - バックグラウンドで実行し、上部に進捗・残り時間・キャンセルを表示。書き出し中も他の操作ができる。キャンセルすると途中のファイルは残さない
8. 「設定」で対象チーム（自チーム。1 つ）とチームのロゴを編集する。`project.json` に保存される
   - **Language / 言語**: 「設定」で日本語と English を切り替える（このパソコンの設定。変えると画面を読み直し、編集中の内容は保存される）。最初の起動は Windows の表示言語に合わせる
   - 文字はコードに日本語で書き、`t('…')` で `src/shared/i18n-en.ts` の英語に置き換える（`{0}` などは値）。英語がない文字は日本語のまま出る。開発版は `VR_LANG=en` で英語で起動できる

### アドオン（選手写真パック）

リーグの選手写真などは、アプリ本体には入れず、別ファイル（`.vrpack`）として足します。
アプリに同梱したパック（インストール先の `resources/packs/`、開発版は `vendor/packs/`）は最初から使え、「アプリに同梱」と出て外せない。同じ id のパックを読み込むと、そちらが使われる。
「設定 → アドオン → パックを読み込む…」で倉庫の `addons/<id>/` に取り込みます。どのプロジェクトからも使えて、「外す」でフォルダごと消えます。
パックが入っていると、右の列に「選手写真」が出ます。
開いているクリップの試合の選手が、合う写真と一緒に並びます（そのプレーの選手は先頭）。
クリックすると、その写真が画像としてクリップかタイトルカードに入ります。
合う写真がない選手は、上の検索欄で名前・チームから探せます。
選手の写真の右上の `✎`（写真がない選手は `＋`）を押すと、画像を選んでその選手の写真を足したり差し替えたりできます。
足した写真は、リーグのパックとは別の「自分で足した写真」（`addons/local/`）に保存されます。リーグのパックを読み込み直しても消えず、リーグの写真より優先されます。
`↺` で自分の写真を外すと、リーグのパックの写真に戻ります。

写真の当て方: DVW の選手ID がパックの `ids` にあれば、それで決めます。
なければ、チームコード（`team` か `teams`）と姓の両方が合うことを条件にします。同じ姓の選手がいるときは、名と背番号で見分けます。
背番号だけでは決めません（別の選手の顔が出ないように）。つづりが違って合わない選手は `ids` に選手ID を足すか、アプリの `✎` で写真を足してください。
姓は大文字小文字・空白・ハイフンを無視して比べます。同点の候補が2人いるときは、どちらも出しません。

パックの作り方: フォルダに `players.csv`（UTF-8。Excel では「CSV UTF-8」で保存）と `photos/` を用意して、次を実行します。

```
node scripts/make-pack.mjs <フォルダ> --id vleague-2026 --name "V.League 2026"
```

`players.csv` の列は `team,jersey,lastName,firstName,label,ids,teams,photo` です。必須は `team`・`lastName`・`photo` の3つです。
`label` は一覧での表示名（例: 山田 太郎）、`ids` と `teams` は `;` 区切りで複数書けます。写真は PNG か JPEG を使います。
選手の写真には肖像権があるため、パックはアプリとは別に、使ってよい範囲の人にだけ配ってください。

SV.LEAGUE の選手名簿から `players.csv` を作る:

```
node scripts/svleague-roster.mjs --out <フォルダ>/players.csv
```

公式サイトのチームごとの選手一覧から、チームコード・背番号・ローマ字の名前（DVW の書き方に合わせる）・日本語の名前（`label`）・ポジションを書き出します。
外国籍の選手は、最初の語を名、残りを姓とします（例: `MARTINEZ CAMPOS` / `Daniel`）。
**写真は取り込みません。** サイトの写真は利用規約で無断の複製・頒布が禁じられているため、`photo` 列は空のままです。使ってよい写真（クラブから提供されたものなど）を `photos/` に入れ、`photo` 列を埋めてください。
同じ `--out` でもう一度実行すると名簿だけを新しくし、埋めた `photo` と `ids` は同じ選手のものを残します。
男子 12 チームのチームコードはスクリプトに入っています。新しいチームなど、コードがわからないチームはサイトの名前のまま書き出して知らせるので、`--codes <サイトの名前>=<コード>` で指定してください。女子は `--list https://www.svleague.jp/team/sv/women/` で、女子チームのコードは `--codes` で指定します。
写真は `photos/` に `<チームコード>_<背番号>.png`（または `.jpg`）の名前で置けば、`photo` 列が空でも `make-pack.mjs` がその選手に紐づけます（例: `HTH_7.jpg`）。
`make-pack.mjs` は、写真のない行を何も言わずに飛ばします（件数だけ表示します）。

## インストーラーを作る

```bash
npm run dist
```

- `release/volley-reel-setup-<版>.exe`（Windows x64、約 180 MB）ができる。ユーザーごとのインストールで管理者権限は不要。インストール先は選べ、デスクトップとスタートメニューにショートカットを作る
- 先に `vendor/ffmpeg/bin` に ffmpeg.exe と ffprobe.exe を置いておく（「準備」参照）。インストーラーには `resources/ffmpeg` として入る（ffmpeg は GPL のビルド）
- アイコンは `build/icon.png`。ffmpeg の LICENSE（GPL v3）と README は `resources/ffmpeg` に同梱する。GPL のため、配布するときは ffmpeg のソースの入手先（ビルド元の配布ページ）も案内すること
- `npm run dist` は手元に作るだけ（公開しない）
- コード署名はしていないので、初回は Windows SmartScreen の「Windows によって PC が保護されました」が出る。「詳細情報」→「実行」で進める
- 設定（倉庫の場所・最近のプロジェクト）は開発版と同じ場所に保存されるので、インストール版でも同じ倉庫・プロジェクトを開ける

## 新しい版を配る（自動更新）

```bash
npm run release
```

- インストールされたアプリ（0.2.0 から）は、起動すると公開リポジトリ [courtendvb/volley-reel-releases](https://github.com/courtendvb/volley-reel-releases) のリリースに新しい版がないか調べ、あれば裏でダウンロードする。終わると上部に「新しいバージョン … の準備ができました」と出て、「再起動して更新」で保存してから新しい版で起動し直す。「あとで」でも、アプリを終了したときに更新される。データ（倉庫・プロジェクト・設定）はそのまま
- 出すとき: `package.json` の `version` を上げてから `npm run release`。インストーラーを作り、そのリリースとして `latest.yml` と一緒に公開する（アプリは自分より高い版だけを取る）。リリースはまず下書きで作り、ファイルがすべて上がってから公開する（アプリは下書きを見ないので、途中の状態を取らない）。アップロードには GitHub CLI のログイン（`gh auth token`）を使う。ソースは非公開のまま、公開されるのはインストーラーだけ
- 0.1.0 には自動更新がないので、最初の 1 回だけ 0.2.0 以降のインストーラーを手で入れてもらう
- 更新のインストーラーは管理者の許可なしで動く（ユーザーごとのインストール）。Windows やセキュリティソフトが裏での起動を止めたときは、管理者として起動し直さず、手で入れるときと同じようにインストーラーを開く。それもできないときは上部に「更新を入れられませんでした」と出て、ダウンロードページと記録を開ける
- 更新の記録: `%APPDATA%\volley-reel\logs\update.log`（「記録を見る」で開く）。うまくいかない人にはこれを送ってもらう
- 上部のアプリ名の横に、今の版（`v0.2.0` など）が出る
- 試すとき: `VR_UPDATE_TEST=1` で開発版が `dev-app-update.yml` の場所（`http://127.0.0.1:8766/`）を見る。インストーラーと、より高い版を書いた `latest.yml` を置いたフォルダを `python -m http.server 8766` などで出すと、見つけてダウンロードするまでを確かめられる。この試しでは更新を入れない（入れるとこの PC のインストール版が置き換わる）

## 保存について

- リールは編集のたびに自動保存（上部に「保存済み / 保存中…」を表示）。ウィンドウを閉じると、保存待ちの変更を書いてから閉じる
- 保存は一時ファイルに書いてディスクへ確実に反映してから置き換え、1つ前の版を `.bak` に残す。読めないファイルは `.bak` から復元して知らせる（壊れた方は `.broken` として残す）
- DVW を修正しても、リールのクリップは同じプレーを指し直す（得点の追加で点数がずれても、時刻を少し直しても追える）。見つからないクリップは消さずに「プレーが見つかりません」と表示する

## 開発用の自己チェック

GitHub Actions（`.github/workflows/ci.yml`）が push と PR ごとに型チェック・単体テスト・ビルドを行う。以下の自己チェックは手元で実行する。自己チェックのコードは `src/renderer/src/smoke.ts` にあり、`VR_SMOKE` のときだけ読み込まれる（通常の起動では読み込まない）。`VR_SMOKE_M8=relink` が書き換える DVW は一時フォルダ内のコピーに限る（それ以外は拒否）。`VR_SMOKE_M8=relocate:<新しい DVW>` で、移動した DVW の表示と指し直しを確認する。

試合を取り込み、絞り込み結果の n 番目に飛んで、ウィンドウのスクリーンショットを保存して終了する
（`VR_SMOKE_SETTINGS=1` で設定ダイアログも開く、`VR_SMOKE_KEYS=3,1,0` でキー入力、`VR_SMOKE_TRIM=1` でループと IN/OUT の操作を確認、`VR_SMOKE_ANN=1` で注釈の描画・移動・表示時刻を確認、`VR_SMOKE_COPY=1` で図形のコピー・貼り付けと、クリップボードの画像の貼り付けを確認（Windows のクリップボードを書き換える）、`VR_SMOKE_PHOTOS=<パック.vrpack>`（と `VR_SMOKE_SCOPE=all`）でパックの読み込み・選手写真の挿入・自分の写真の追加と取り消しを確認（パックに、試合に出た選手がいること）、`VR_SMOKE_COURT=1` でコートのグリッドの合わせ込み（四隅のドラッグ）・試合への保存・手前のチームの入れ替え・プレーのゾーン（サブゾーン・トス）と、画像をコートに遠近で重ねる操作、透明度のスライダー（実際のマウスとキー）を確認（`VR_SMOKE_EXPORT=<出力.mp4>` を足すとコートを入れて書き出す）、`VR_SMOKE_OV=1`（または `dialog`）でオーバーレイを確認、`VR_SMOKE_EXPORT=<出力.mp4>` で書き出し・フレーム確認・キャンセルを確認、`VR_SMOKE_M8=relink|flush-write|report|undo`（と `VR_SMOKE_CORRUPT=1`）で再リンク・終了時保存・復元・元に戻すを確認、`VR_SMOKE_VIDEO=1`（と `VR_SMOKE_EXPORT`）で動画・共有シーン・元に戻す・書き出しを確認、`VR_SMOKE_OBJ=1`（と `VR_SMOKE_EXPORT`、`VR_SMOKE_ASSETS=<画像;PDF>`）で図形・三角形・頂点の編集・書式・画像の挿入・書き出しを確認、`VR_SMOKE_SLIDES=1`（と `VR_SMOKE_EXPORT`、`VR_SMOKE_ASSETS=<PDF;画像>`）でスライドの右クリックのメニュー・スライドの図形・PDF のページ・静止画・ドラッグ・通し再生・元のファイルの読み直し・書き出しを確認（ファイルはプロジェクトにコピーして使う）（`VR_SMOKE_MEM=<秒>` を足すと再生中のメモリ・CPU・描画回数を測る）、`VR_LIBRARY=<倉庫> VR_SMOKE_HOME=scan|import-create|home|picker|auto-create VR_SMOKE_FOLDERS="<フォルダ>;…"` で倉庫とプロジェクト作成を確認、
`VR_SMOKE_SAVEDFILTERS=1` で保存条件の保存・呼び出し・置き換え・削除と元に戻すを確認、`VR_SMOKE_REEL='{"markers":[2,1,null],"scope":"all"}'` で結果からリールを作って通し再生し、切り替え時間を測る）。試合は `;` 区切りで複数指定できる。

```bash
VR_PROJECT="C:\path\to\project" VR_IMPORT="C:\video\a.mp4|C:\scout\a.dvw;C:\video\b.mp4|C:\scout\b.dvw" VR_SMOKE="C:\path\to\smoke.png" VR_SMOKE_SCOPE=all VR_SMOKE_FILTER='{"person":"YAN-YUR-02","skills":["S"]}' VR_SMOKE_PLAY=0 npx electron .
```

実データの .dvw でパーサーを確かめるときは `VR_DVW_DIR=<フォルダ> npm test`。
