# 宣伝の方針（打合せメモ 2026-11）

volley-reel をどう宣伝するかを、作者と打ち合わせて決めた内容。

## 名前

- **SyncScout Video Editor** にする（英語名）。作者の Web サービス SyncScout と同じ課金システムに組み込み、シリーズとして並べる
- 「reel」は使わない。日本では Instagram のリールに聞こえ、何をするソフトか伝わりにくい
- 候補だった「Volleyball Loom」は、名前ではなく宣伝の言葉（「プレーを織り上げる」）として使える。Loom 単独は有名な画面録画ソフトと被るので使わない

## 役割分担

| | SyncScout | SyncScout Video Editor |
|---|---|---|
| 一言で | 元の映像を**探して見る** | 見せたい映像を**飾って仕上げる** |
| 動く場所 | Web | パソコン（オフライン） |
| 映像 | YouTube の動画＋スカウトファイル | 手元の動画ファイル＋ .dvw |
| 場面 | チームで共有・閲覧 | ミーティング、スタッフが見せたい映像 |

シリーズの一文: **SyncScout で探して、Video Editor で伝える。** / *Find it in SyncScout. Tell it with Video Editor.*

## コンセプト

既存の分析ソフトの良いところを合わせ、さらに機能を足したもの。

- DataVolley のモンタージュの**構築力**（違う検索を合わせて1本に組める）
- VolleyStation の**手軽さ**（選ぶ・並べるが楽）
- その上に、注釈・テロップ・スコアボード・タイトルカード・コート上のデータ表示を足した

前提: DataVolley も VolleyStation も映像の編集はできる。「映像を作れる」こと自体は違いにならない。

## 宣伝の軸（2本）

1. **データを映像のコートに重ねる**: ヒートマップ・ゾーン・座標・軌道（放物線）・落下点・サーブ軌道。SyncScout の名前（映像とスカウトの同期）を一番よく表す機能
2. **ミーティング向けに仕上げる**: 注釈（文字・矢印・図形・画像）・選手テロップ・スコアボード・タイトルカード

軸にしないもの（機能の紹介に書く程度）:
- 選んで組む作り方（足し算。100本から削らない）
- いつでも作り直せる（選択・トリム・注釈が全部残る）
- クリップごとの IN/OUT、スロー・停止

## 宣伝文句

採用:
- **DataVolley の構築力と VolleyStation の手軽さを1本の流れに。注釈・テロップ・スコアボードまで1画面で。**（内部向け・説明用。公開ページでは競合名を出さない）
- 英語（競合名なし）: *Build like a pro analysis suite, edit with ease — in one workflow. Annotations, captions and scoreboard, all on one screen.*

候補:
- ミーティングで伝わる映像を、1画面で。 / *Meeting-ready video, on one screen.*
- 見せたいプレーを、見せたい形で。 / *The plays you want to show, the way you want to show them.*
- データが、コートの上に見える。 / *See the data on the court.*
- ボールの行き先を、映像の上に。 / *Where the ball went, drawn on the video.*

不採用: 「削るのではなく、選ぶ」「作ったビデオは、いつでも作り直せる」（AI くさい）

## 書き方の決まり

- **競合の名前を出しすぎない。** 比較すると「代わり」「真似」に見える。違いは機能の具体的な説明で伝える。他社名を宣伝に使うのは比較広告の問題にもなりうる
- 「他に類を見ない」「唯一」のような言い切りはしない。何ができるかを具体的に書く
- 自動でクリップを選ぶ機能は作らない（手で選ぶほうが確実、と作者）

## 既存ソフトについて分かっていること（検索の抜粋より。原文は未確認）

- DataVolley 4: 書き出し・モンタージュは Professional 版のみ。モンタージュは複数試合・複数検索を合わせ、文字・描き込みを足せる
  - 作者の不満: 検索結果から1本ずつ外していく引き算の作りが手間（サンプルの少ない選手に合わせて試合を増やすと、多い選手は100本前後から削る）。作成途中の選択や編集過程が消え、あとで作り直せないことがある
- VolleyStation: チェックと6色の旗で選び、ドラッグで並べ替え。オーバーレイでローテ・セット・得点・相手名を出せる。違う要素を1本にまとめるのは苦手
  - 作者の不満（design.md）: 注釈が入れられない。クリップの長さを1本ずつ決められない
