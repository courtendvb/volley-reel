# volley-reel

DataVolley のスカウトファイル（.dvw）と試合動画を同期させ、
選手に見せるハイライト動画（MP4）を作るローカルアプリ（Windows / オフライン / Electron）。

- 設計図: [docs/design.md](docs/design.md)
- 状況: M0（書き出し検証）完了、M1（取り込み・DVW パース・再生）、M2（検索・絞り込み・自チーム設定・名寄せ）、M3（リール・マーカー・並べ替え・通し再生）、M4（クリップごとの IN/OUT）、M5（注釈）、M6（スコアボード・選手テロップ・タイトルカード）、M7（MP4 書き出し）実装済み

## 準備

1. `vendor/ffmpeg/bin/` に ffmpeg.exe / ffprobe.exe を置く（gyan.dev の essentials ビルド。git 管理外）
2. `npm install`

## 使い方

```bash
npm run dev        # 開発モードで起動
npm run build      # out/ にビルド
npm start          # ビルド結果を起動
npm test           # DVW パーサーのテスト
npm run typecheck
```

1. 「プロジェクトを開く」で保存先フォルダを選ぶ（`project.json`、`matches/*.json`、`cache/` ができる）
2. 「試合を取り込む」で動画と .dvw を選ぶ
   - 再生できる形式（H.264 4:2:0、音声 AAC など）は**元の動画をそのまま参照**する
   - リニアPCM 音声（XAVC S）は音声だけ外したコピーを、4:2:2 / 10bit などは変換したものを `cache/` に作る
3. 左のプレー一覧をクリックすると、そのプレーの 2 秒前から再生する（別の試合のプレーなら動画も切り替わる）
4. 絞り込み: 「この試合 / 全試合」、チーム（自チーム / 相手）、選手、スキル、評価、セット、ローテ、開始・終了ゾーン
   - 選手は DataVolley の選手IDで、試合をまたいで同じ人として扱う（ホーム/アウェイ、紅白戦の `-a` も統合）
   - ローテは、そのプレーをしたチームのローテ
   - 全部ホーム入力の試合はチームを区別できないので、チームで絞っても全プレーを含める
5. 右のリール: プレー一覧の「＋」か「結果をリールに追加」でクリップを入れる。リールは `reels/<id>.json` に自動保存（削除すると `reels/deleted/` に移動）
   - マーカー 1〜5 でグループ分けし、グループに名前を付けられる。グループ同士・グループ内の順序は ↑↓ かドラッグで並べ替え
   - 書き出し範囲: 「マーカー付き」はマーカーのグループ順、「全部」はその後にマーカーなしを時系列で
   - 「通し再生」でその順に再生（試合をまたぐと動画が切り替わる）
   - 長さの初期値はリールごとに「ラリー全体」（サーブ −1.5 秒〜最後のプレー +2.5 秒）か「キープレー中心」（−3〜+4 秒）。秒数も変えられる
   - リールのクリップをクリックすると、その範囲をループ再生しながら動画の下のトリムバーで IN/OUT を詰められる
     （つまみをドラッグ、`[` `]` キー、またはキープレーからの秒数を入力。「既定に戻す」で初期値に戻る）
   - 同じ試合で範囲が重なるクリップ（同じラリーの2プレーなど）には ⚠ が付く。警告だけで、両方残る
   - 注釈: 選択中のクリップの動画の上に、テキスト・矢印・円・四角・フリーハンドを描ける（色・線の太さ・文字サイズを選択）
     - 選択ツールでクリックして選び、ドラッグで移動、ダブルクリックでテキストを編集、`Delete` で削除
     - 「ここから表示」「ここで消す」で出し入れの時刻を決める（既定はクリップ全体）。時刻は動画上の絶対時刻で保存するので、IN を詰めてもずれない
     - 座標は動画に対する 0〜1 で保存。編集中は、今の時刻では表示されない注釈も薄く表示する
   - 自動オーバーレイ: スコアボード（ラリー開始前の点数、自チームが左）と選手テロップ（背番号・名前・スキル・評価）を
     DVW から自動で表示。リールの「オーバーレイ」で、要素ごとに表示・位置・サイズ・項目と、配色（プリセットか自由指定）を設定
     - タイトルカード（マーカーグループの頭、マーカー名と試合名）も選べる。通し再生ではグループの前に設定秒数だけ出る
     - クリップごとに、動画の下の「自動表示」でスコアボード／テロップを隠したり、テロップの名前・2行目を書き換えたりできる
   - 「MP4 に書き出す」: 書き出し範囲のクリップを、通し再生と同じ順（タイトルカード込み）で MP4（H.264、音声なし）にする
     - 出力は 720p・素材のフレームレート。既定の保存先はプロジェクトの `exports/`
     - 注釈・スコアボード・テロップ・タイトルカードは、プレビューと同じ描画で PNG にして焼き込む。表示時刻のある注釈は `enable` で出し入れ
     - バックグラウンドで実行し、上部に進捗・残り時間・キャンセルを表示。書き出し中も他の操作ができる。キャンセルすると途中のファイルは残さない
6. 「設定」で自チームのチームコード（既定 `HTH, HTA`）と名寄せ表（IDが違うのに同じ人の指定）を編集する。`project.json` に保存される

| キー | 動作 |
|---|---|
| `Space` | 再生 / 一時停止 |
| `←` `→` | 0.5 秒戻る / 進む |
| `Shift` + `←` `→` | 1 フレーム戻る / 進む |
| `1`〜`5` | 選択中のクリップにマーカー（同じ数字か `0` で解除）。リールにないプレーを選んでいれば、そのマーカーで追加 |
| `[` / `]` | 再生位置を選択中のクリップの IN / OUT にする |
| `V` `T` `A` `C` `R` `F` | 注釈ツール: 選択 / テキスト / 矢印 / 円 / 四角 / フリーハンド |
| `Delete` | 選択中の注釈を削除 |
| `Esc` | 通し再生を止める |

## 開発用の自己チェック

試合を取り込み、絞り込み結果の n 番目に飛んで、ウィンドウのスクリーンショットを保存して終了する
（`VR_SMOKE_SETTINGS=1` で設定ダイアログも開く、`VR_SMOKE_KEYS=3,1,0` でキー入力、`VR_SMOKE_TRIM=1` でループと IN/OUT の操作を確認、`VR_SMOKE_ANN=1` で注釈の描画・移動・表示時刻を確認、`VR_SMOKE_OV=1`（または `dialog`）でオーバーレイを確認、`VR_SMOKE_EXPORT=<出力.mp4>` で書き出し・フレーム確認・キャンセルを確認、
`VR_SMOKE_REEL='{"markers":[2,1,null],"scope":"all"}'` で結果からリールを作って通し再生し、切り替え時間を測る）。試合は `;` 区切りで複数指定できる。

```bash
VR_PROJECT="C:\path\to\project" VR_IMPORT="C:\video\a.mp4|C:\scout\a.dvw;C:\video\b.mp4|C:\scout\b.dvw" VR_SMOKE="C:\path\to\smoke.png" VR_SMOKE_SCOPE=all VR_SMOKE_FILTER='{"person":"YAN-YUR-02","skills":["S"]}' VR_SMOKE_PLAY=0 npx electron .
```

実データの .dvw でパーサーを確かめるときは `VR_DVW_DIR=<フォルダ> npm test`。
